# MiVueltica — Frontend implementation plan (v1, 2026-10-31)

Authority: `docs/requirements.pdf` (takes precedence) + Figma `hK6ZmxpUjxlz7NT3fxoFVd` (visual source). Stack: Expo SDK 58, RN 0.88, Expo Router, TypeScript. Frontend only; every API goes through a local mock service behind an interface.
Note: the PDF skips NFR-5..NFR-8.

## 0. Ground rules
- Read `AGENTS.md`. Before using any Expo API fetch `https://docs.expo.dev/versions/v58.0.0/sdk/<module>/`. Install with `npx expo install <pkg>` (no bun.lock).
- Routes only in `src/app/`; everything else in `src/{components,features,domain,data,state,theme,i18n,lib}`.
- Never edit `ios/` or `android/`; configure via `app.config.ts` / config plugins.
- Done per milestone: `npx expo lint`, `npx tsc --noEmit`, `npm test` (unit), `npm run e2e` (Playwright) pass.
- Remove starter content: `src/app/explore.tsx`, starter `index.tsx`, animated splash/icon components, starter web badge, logo assets.

- F16 Offline: banner "Sin conexión" + Reintentar; show saved/recent from cache; network actions disabled.

Business rules → `src/domain/rules.ts`, unit-tested:
- Tiers: gratis (0), hasta2500 (1–2.500), hasta5000 (2.501–5.000); >5.000 rejected at submit / hidden if verification shows it.
- Votes to publish: 5, or 3 if author level ≥3. Majority decides. Moderators level ≥3 (level 5 votes count double — placeholder). Vote undoable. Pending visible only to author + moderators.
- 3 matching verification changes update listing; price >5.000 or gone → hidden. 3 matching reports hide while under review.
- Points: +10 published, +2 verify, +1 review useful, +1 moderation vote; penalties placeholder below.
- Browsing/filtering/directions/reading reviews need no account; save/submit/review/moderate need sign-in. Account delete removes profile/reviews/pending; published stay "Anónimo".
